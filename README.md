# NotedSuite Homebrew tap

```bash
brew install --cask notedsuiteapps/tap/quality-noted
```

| Cask | App |
|---|---|
| `quality-noted` | [Quality.Noted](https://quality.notedsuite.app): release-readiness QA audits for Mac apps, run by your own Claude Code. Free to try. |

Apps update themselves; `brew upgrade --cask --greedy` also works.
